# Qubes KDE Baseapps (obsolete)

This repository is obsolete and no longer used. It is left over from KDE 4
support.

It held the [Qubes OS](https://www.qubes-os.org) packaging of the upstream KDE
baseapps suite. It downloaded the upstream `kde-baseapps` source tarball and
built an RPM from it. A Qubes patch dropped most of the suite and kept tools
such as `kdialog` (shell dialog boxes) and `kdepasswd`.
